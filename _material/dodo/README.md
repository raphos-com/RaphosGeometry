# Stylized dodo

Original procedural mesh with 36,304 triangles in 46 named components.

- dodo.glb: self-contained materials and smooth normals; Y up.
- dodo.obj + dodo.mtl: editable components; Z up. Keep both files together.
- dodo-preview.png: rendered mesh preview.
- create_dodo.py: regenerate using Python, NumPy and Pillow.

Units are metres; height approximately 1.12 m. Individual components are closed triangulated surfaces. Components overlap and are not boolean-unioned, so this is a visualization asset, not a prepared single-shell print model. No rig, animation or UV textures. Colors are material based.
